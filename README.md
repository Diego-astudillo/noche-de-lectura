# 🐰🐻 Noche de lectura

Una conejita y un osito leyendo bajo las estrellas. HTML + CSS + JavaScript, sin dependencias.

- Animaciones: estrellas, estrella fugaz, luciérnagas, orejas, parpadeo y páginas que pasan.
- Toca a los personajes para ver corazones.
- Botón para cambiar el mensaje.

## Ver en GitHub Pages
Sube los archivos, ve a **Settings → Pages**, elige la rama `main` y carpeta `/ (root)`.
